Cara Akses Aplikasi

1

Buka Chrome di HP

Gunakan browser Chrome, bukan browser bawaan HP lainnya

2

Ketik alamat aplikasi

pkl.smkn1kismantoro.sch.id di address bar lalu Enter

3

Login dengan akun kamu

Username & password dari guru/admin. Lupa? Hubungi guru.

4

Install ke homescreen

Menu ⋮ di Chrome → Add to Home Screen → Install

Cara Isi Presensi Harian

1

Buka menu Presensi

Ketuk Presensi di sidebar atau tombol "Isi Presensi Hari Ini"

2

Pilih status kehadiran

Hadir / Izin / Sakit / Libur

3
WAJIB

Foto selfie

Wajib jika Hadir. Foto otomatis dikompresi.

4
WAJIB

Isi deskripsi kegiatan

Tulis singkat kegiatan hari ini. Wajib jika Hadir.

5

Izinkan akses GPS

Ketuk Izinkan saat browser minta akses lokasi

6

Kirim presensi

Ketuk tombol Kirim Presensi. Selesai!

Edit Presensi

Edit hanya bisa dilakukan sampai H+1. Lewat dari itu, presensi dikunci otomatis oleh sistem.
1

Buka menu Presensi

Ketuk menu Presensi di sidebar

2

Cari tanggal yang ingin diedit

Presensi yang bisa diedit ditandai tombol Edit

3

Ketuk tombol Edit

Ubah status, foto, atau deskripsi sesuai kebutuhan

4

Simpan perubahan

Ketuk Simpan. Berlabel "Terlambat Input" jika diedit di H+1

Batas Waktu Presensi

Hari H
BISA ISI
Hari H
Bisa isi presensi kapan saja sepanjang hari. Tidak ada batasan waktu.
H+1
MASIH BISA
Keesokan harinya
Masih bisa isi atau edit presensi, tapi berlabel "Terlambat Input". Usahakan jangan sampai di sini.
H+2
DIKUNCI
Dua hari setelahnya
Presensi dikunci otomatis oleh sistem. Tidak bisa diubah lagi. Tercatat sebagai Tidak Hadir.
