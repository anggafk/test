Konfigurasi Dasar Router

1. Reset Konfigurasi MikroTik

Menghapus semua konfigurasi Router MikroTik dan mengembalikan ke pengaturan awal.

  1. a
    System → Reset Configuration.
  2. b
    Beri tanda ✔ pada No Default Configuration.
    Jika dicentang, Router akan benar-benar kosong setelah reset. Jika tidak dicentang, Router akan kembali ke konfigurasi bawaan pabrik.
  3. c
    Klik tombol Reset Configuration → Yes.
  4. d
    Tunggu beberapa saat dan koneksi dengan Router akan terputus. Kemudian ulangi proses menghubungkan Router dari awal.
💡 Keterangan opsi lainnya:
Keep Users — jika dicentang, data pengguna (username & password) yang sudah dibuat tidak akan ikut dihapus.
Do Not Backup — jika dicentang, Router tidak akan membuat file backup otomatis sebelum melakukan reset.

2. Konfigurasi Hostname

Mengubah nama Router MikroTik.

  1. a
    System → Identity.
  2. b
    Isikan Nama Router pada kotak Identity.
  3. c
    Klik tombol Apply → OK.

3. Konfigurasi Alamat IP

  1. a
    IP → Addresses.
  2. b
    Klik tombol + untuk menambah alamat IP.
  3. c
    Isikan sesuai ketentuan berikut:
    IP Address: [Alamat IP]
    Network: [Alamat Network]
    Interface: [Port yang dipakai]
  4. d
    Klik tombol Apply → OK.
Contoh Alamat IP:
Address  : 192.168.10.1/24
Network  : 192.168.10.0
Interface: ether1

4. Konfigurasi IP DNS

DNS (Domain Name System) berfungsi menerjemahkan nama domain (seperti google.com) menjadi alamat IP. Router perlu dikonfigurasi DNS agar bisa mengakses internet menggunakan nama domain.

  1. a
    IP → DNS.
  2. b
    Isikan IP DNS Primer di kotak Servers.
  3. c
    Gunakan tombol segitiga di bagian kanan untuk menambah atau menghapus IP DNS.
  4. d
    Beri tanda ✔ pada opsi Allow Remote Request — digunakan agar Router MikroTik berfungsi sebagai DNS Server.
  5. e
    Klik tombol Apply → OK.
Contoh IP DNS:
Google DNS     : 8.8.8.8 / 8.8.4.4
Cloudflare DNS : 1.1.1.1 / 1.0.0.1
💡 Menggunakan IP Gateway sebagai DNS
Jika jaringan sudah menyediakan DNS Server (misalnya dari ISP), kamu bisa menggunakan IP Gateway sebagai DNS Server. Caranya isikan alamat IP Gateway di kolom Servers. Dengan begitu, permintaan DNS dari Router akan diteruskan ke DNS milik ISP secara otomatis.

5. Konfigurasi NAT

NAT (Network Address Translation) adalah proses penerjemahan alamat IP dari jaringan lokal (private) ke alamat IP publik agar perangkat di jaringan lokal bisa mengakses internet. Tanpa NAT, paket data dari jaringan lokal tidak akan bisa diteruskan ke internet karena alamat IP private tidak dikenali di jaringan publik.

  1. a
    IP → Firewall → NAT.
  2. b
    Klik tombol + untuk menambah NAT.
  3. c
    Atur sesuai ketentuan berikut:
    Tab General — Chain: srcnat, Out. Interface: [port yang digunakan]
    Tab Action — Action: masquerade
  4. d
    Klik tombol Apply → OK.
💡 Konfigurasi ini diulang sesuai jumlah port yang digunakan.

6. Konfigurasi Gateway

Gateway adalah pintu keluar jaringan lokal menuju jaringan lain, termasuk internet. Biasanya berupa alamat IP Router ISP atau perangkat upstream yang terhubung ke internet. Tanpa gateway, Router tidak tahu harus meneruskan paket ke mana saat tujuannya berada di luar jaringan lokal.

  1. a
    IP → Routes.
  2. b
    Klik tombol + untuk menambah IP Gateway.
  3. c
    Isikan IP gateway di kotak Gateway.
  4. d
    Klik tombol Apply → OK.
Contoh IP Gateway:
Gateway: 192.168.10.254

7. Pengujian Koneksi Jaringan

  1. a
    Buka New Terminal di Winbox.
  2. b
    Uji koneksi jaringan menggunakan perintah ping dengan format: ping [alamat tujuan]
  3. c
    Tekan Enter.
Contoh:
Pengujian ke alamat web
    ping google.com

Pengujian ke perangkat jaringan (PC, Router, dll)
    ping 192.168.10.1
